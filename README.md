# Pomodoro Timer

A focus timer built around the Pomodoro Technique — structured work sessions with breaks to maximize productivity.

Live demo: [pomodoro-timer-two-lilac.vercel.app](https://pomodoro-timer-two-lilac.vercel.app/)

---

## What It Does

- **Work/break sessions** — timed focus intervals followed by break periods
- **Task management** — add and track tasks within your session
- **Clean reset** — timer resets to a fresh state on refresh

---

## Built With

- HTML
- CSS
- JavaScript (Vanilla)

---

## How to Use

1. Add your tasks for the session
2. Start the timer and focus until it ends
3. Take your break when prompted
4. Repeat

---

## Run Locally

```bash
git clone https://github.com/Dev-Opeyemi/pomodoro-timer.git
cd pomodoro-timer
```

Open `index.html` in your browser. No dependencies, no install.
